# REA research notes

- The official [`morluto/rea`](https://github.com/morluto/rea) repository was cloned for static reference.
- REA CLI 6.5.0 was run with a temporary Node 24.11.1 runtime. Its `doctor` command confirmed the runtime was available; Hopper, Ghidra, and IDA were not configured in this environment.
- A read-only analysis was performed on a public example from the open-source [openDAW](https://github.com/andremichelle/openDAW) repository. No source code or assets were copied into BeatCraft Studio.
- No paid DAW binaries, DRM, account flows, proprietary sample packs, or commercial product assets were inspected or copied.

BeatCraft Studio is an original Rust native desktop application using `eframe`/`egui` for its UI and CPAL for audio I/O. It uses general music-production concepts such as tracks, sequencing, tempo, swing, arrangement, synthesis, and mixing without copying commercial product code, branding, or assets.
